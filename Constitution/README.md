# Constitution

The Constitution is the highest authority within the AI Movie Skills Repository.

It defines the permanent principles, standards, and governance rules that all repository artifacts, contributors, and AI systems must follow.

# Governance Hierarchy

When multiple repository artifacts define related rules, the following order of precedence applies.

```
Constitution
        ↓
Repository Standards
        ↓
Templates
        ↓
Schemas
        ↓
Knowledge
        ↓
Registry
```

The higher level always takes precedence.

For example:

- If a template conflicts with the Constitution, the Constitution is correct.
- If a knowledge file conflicts with the Repository Standards, the Repository Standards are correct.
- If registry metadata conflicts with the corresponding knowledge file, the knowledge file is the source of truth.

This hierarchy ensures consistent governance across the repository.
