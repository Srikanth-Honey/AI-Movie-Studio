# Definition

Moral Faction Color Temperature Coding is a lighting design principle in which each morally distinct faction or character group in a scene is consistently lit with a different color temperature, creating an unconscious visual taxonomy that audiences register before consciously processing story information. The system typically assigns: fire-warm elemental temperatures (~1800K–2200K) to heroic/moral characters; controlled institutional warm temperatures (~3000K–3400K) to authority/establishment characters; and cool-shadowed crimson tones (~2400K with deep red rim) to corrupt or villainous characters.

# Purpose

This skill solves the problem of how to continuously reinforce moral alignment information without relying on dialogue, costume changes, or explicit characterization. Consistent color temperature assignment creates a visual language that the audience learns automatically during a scene and then reads instantaneously for the remainder of the film.

# Psychology

Color temperature triggers automatic emotional responses rooted in evolutionary biology: fire-warm temperatures (~1800K–2200K) activate associations with the most ancient human light source — campfire, hearth — generating responses of safety, community, and spiritual presence. Institutional amber (~3000K–3400K) is associated with controlled, artificial illumination — order, institution, civilization, also slightly cold by comparison to fire. Cool-blue or crimson shadow lighting activates isolation, danger, and predatory associations. These responses are cross-cultural and below conscious processing.

# Story Function

The color temperature system allows the audience to quickly orient within a complex ensemble scene. When five or more characters are in frame, the audience cannot process all characterization simultaneously — but they can instantly register light temperature on each face and apply the established moral coding. The technique is particularly powerful in wide shots where facial expression is too small to read: the audience reads moral alignment from the overall color palette of each figure.

# Character Function

Each faction's light temperature becomes part of their visual identity:
- **Heroic/Moral** characters: Fire-warm (~1800K–2200K). Associates them with elemental purity, ancient wisdom, and spiritual presence. Their warmth is primal and genuine — the oldest light humans have ever known.
- **Institutional/Authority** characters: Controlled amber (~3000K–3400K). Warmer than daylight but cooler than fire — organized power, civilization, order without spiritual authenticity.
- **Corrupt/Villainous** characters: Cool-shadowed with deep crimson rim (~2400K + red/crimson rim or shadow fill). The crimson rim signals danger; the shadow fill removes the warmth of connection.

# External Behaviour

The color temperature assignment should remain consistent across all scenes and setups featuring the same character groups. Deviations from the established color temperature coding should signal moral shifts — if a heroic character begins receiving institutional amber light, it may foreshadow their compromise of values; if an institutional character receives fire-warm light, it signals their alignment with the protagonist's moral position.

# Body Language

Not applicable directly, though the warm fire light naturally produces deeper shadows on facial features due to its directional, close-proximity source — this tends to create more sculptural modeling on moral characters' faces, reinforcing the sense of depth and moral complexity.

# Timing

The color temperature coding must be established in the scene's first wide or establishing shot. Once the audience has seen each character lit in their assigned temperature, the coding is active for the remainder of the scene. Subsequent close-ups in consistent temperature reinforce the coding without requiring re-establishment.

# Rhythm

The coding is continuous and consistent — not a rhythmic element. Its strength comes from unwavering application: a single shot where a heroic character is lit with institutional amber without narrative purpose will confuse the established code.

# Camera Considerations

The color temperature coding is most readable on skin tones in medium-close to close-up framing. In extreme wide shots, the coding must be strong enough (sufficient exposure differential between temperature zones) to remain visible at small portrait sizes.

# Lighting Considerations

**Heroic Temperature (~1800K–2200K):**
- Achieved through practical flame sources (braziers, torches, candles) or tungsten fixtures gelled with full CTO plus additional warm gel to pull below standard tungsten
- Source should be directional (single source or strong key) to create clear facial modeling
- Catchlights in the eyes should appear amber-gold

**Institutional Temperature (~3000K–3400K):**
- Standard tungsten (~3200K) without gel modification — this is the "default warm" reading as controlled power
- Multiple source setup acceptable — institutional characters occupy a lit, organized space
- Catchlights appear white-gold

**Corrupt/Villainous Temperature (~2400K + crimson rim):**
- Deep amber-shadow key combined with a red-gelled rim or back light — the warm key suggests proximity to institutional power; the crimson rim signals the corruption underneath
- High contrast: minimal fill, strong key-to-fill ratio (8:1 or higher) to create dramatic shadow on non-lit side of face

# Music & Sound Considerations

Not directly applicable. However, the color temperature system can be coordinated with the score's orchestral color — string-heavy warm tones for heroic characters, brass-heavy for institutional, discordant or low-register for corrupt — creating a cross-sensory moral coding system.

# Best Used When

- A scene contains 3+ morally distinct factions or character alignments.
- The genre supports stylized visual language (epic, historical, fantasy, thriller).
- The scene is long enough that the audience benefits from a visual shorthand for moral alignment.
- Multiple characters appear in wide shots where facial expression detail is limited.
- The moral alignment of characters shifts during the narrative (requiring temperature transitions).

# Avoid When

- The genre is committed to naturalistic lighting (dogme, fly-on-the-wall documentary style) where controlled color temperature assignment would break the aesthetic contract.
- Character moral alignment is intentionally ambiguous — the coding system presupposes clear factional structure.
- The setting does not offer sufficient lighting control to maintain consistent temperature assignments across complex ensemble setups.

# Common Mistakes

- Allowing consistency to lapse in intermediate coverage shots — the coding must hold in every medium, medium-close, and close-up framing.
- Applying the same institutional temperature to heroic and institutional characters — the ~1000K difference between fire-warm and institutional amber is the essential coding signal.
- Using color grading to introduce temperature coding in post without planning it on set — grading can reinforce but cannot fully replace the depth-of-field and practical-light texture of on-set temperature design.
- Forgetting to coordinate the temperature coding with the color grade: if the color grade is cool-shifted across the board, fire-warm sources will still read as institutional amber.
