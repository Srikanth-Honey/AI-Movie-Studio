# Knowledge

Purpose: Store timeless, reusable filmmaking knowledge and skills.

Structure:
- `Knowledge/<Domain>/<Subdomain>/README.md`

Guidelines:
- This folder contains only reusable filmmaking knowledge.
- Each Markdown file represents one reusable skill or principle.
- Folders represent stable knowledge domains (not projects or people).

Prohibitions (never store here):
- movie-specific knowledge
- actor-specific behaviour
- generated prompts or generated outputs
- implementation details or runtime artifacts

This taxonomy supports large-scale, long-lived knowledge growth while remaining stable and discoverable.
