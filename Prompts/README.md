# Prompts

## Purpose

This folder contains the permanent AI prompts used to interact with the AI Movie Skills Repository.

These prompts define **execution workflows**.

They do **not** define repository governance.

Repository governance is defined exclusively by the Constitution.

---

# Responsibility

The prompts are responsible for:

- defining AI roles
- defining execution workflow
- defining expected inputs
- defining expected outputs
- orchestrating repository interaction

The prompts must never redefine:

- repository philosophy
- knowledge philosophy
- skill creation standards
- repository standards
- quality standards
- naming standards
- review standards

Those responsibilities belong exclusively to the Constitution.

---

# Prompt Hierarchy

The Master Prompt is the permanent system prompt used for repository knowledge generation.

It should be used for every video analysis session.

The prompt is intentionally lightweight.

Most repository intelligence resides within:

- Constitution
- Templates
- Knowledge
- Registry

The Master Prompt orchestrates these components rather than replacing them.

---

# Maintenance

The Master Prompt should remain stable.

When repository rules change, update the Constitution instead of embedding new rules into the prompt whenever possible.

The prompt should evolve only when the execution workflow changes.

---

# Guiding Principle

Keep prompts simple.

Keep repository knowledge permanent.

Keep governance inside the Constitution.
