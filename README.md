AI Movie Skills — Permanent Reusable Filmmaking Knowledge Repository

Purpose
- Store timeless, reusable filmmaking skills and knowledge.
- Provide a long-lived foundation for the AI Movie Skills knowledge base.
- Support discoverability, metadata validation, and maintainable governance.

What this repo provides
- Constitution documents for governance, standards, and Git-first workflow.
- Reusable Knowledge organized into stable filmmaking domains.
- A canonical Skill Registry storing metadata only.
- Persistent schemas for valid knowledge and registry artifacts.
- Templates for skill authoring, knowledge entries, reviews, and metadata.
- Repository tooling guidance and documentation.

Repository scope
- Only reusable filmmaking knowledge and repository governance belong here.
- No movie projects, media assets, generated prompts, automation pipelines, or runtime systems.
- No production-specific entities such as characters, locations, voices, or props.

Structure
- `Constitution/` — governance, standards, and repository operating rules.
- `Knowledge/` — reusable filmmaking knowledge across stable domains.
- `Registry/` — skill metadata registry, index-only.
- `Schemas/` — validation schemas for repository artifacts.
- `Templates/` — production-ready templates for knowledge creation.
- `Tools/` — repository tooling and utilities.

Getting started
- Follow the Git workflow guidance in `Constitution/10_Git_Workflow.md`.
- Add new knowledge entries under the appropriate `Knowledge/` domain.
- Add skill metadata to `Registry/SkillRegistry.json` without duplicating full content.
