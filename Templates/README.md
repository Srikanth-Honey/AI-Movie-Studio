# Templates

Purpose: Reusable authoring templates for the AI Movie Skills repository.

Templates provide consistent structure for persistent repository artifacts.

Current templates:
- `SkillTemplate.md` — metadata-first skill authoring.
- `KnowledgeTemplate.md` — reusable knowledge content.
- `ReviewTemplate.md` — review and approval artifacts.
- `MetadataTemplate.md` — metadata authoring guidance.

Template filenames use `snake_case` and reflect their content purpose.
