# Repository Tooling

Purpose: Store repository utilities and tooling guidance that support knowledge governance, validation, and contributor workflows.

This folder should contain small, documented utilities and scripts that help maintain the repository (validation, indexing, linting). Tools that implement project-specific runtime behavior belong in other repositories.

Note: Template filenames in this repository use PascalCase (for example: `SkillTemplate.md`, `KnowledgeTemplate.md`, `ReviewTemplate.md`, `MetadataTemplate.md`).
